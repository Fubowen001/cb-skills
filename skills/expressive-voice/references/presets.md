# 项目声音来源与可复用预设

《元日》的声音先使用 Qwen3-TTS-12Hz-1.7B-CustomVoice 的 MLX 4-bit 版本生成，随后用 Qwen3-TTS-12Hz-1.7B-Base 的 MLX 4-bit 版本固定教师与学生声音。项目实际运行环境为 mlx-audio 0.6.5、MLX 0.32.4、Apple Silicon。

## 学生声音的生成链

1. 初始说话人为 `Vivian`，角色指令为“你在给动画片里的小书童阿禾配音：八九岁孩子的好奇和灵气，清亮、有朝气，遇到问题很认真。像刚刚亲眼看到一样说，句尾有自然起伏。”
2. 具体场景附加意图。团圆饭场景为“想到全家吃饺子的旧事，温馨而有一点想念。”疑问句补充“心里真的想知道答案，带一点上扬的疑问。”
3. 初始候选使用 temperature 0.69、top_p 0.89。需要定向补录时曾使用 temperature 0.64、top_p 0.88。这些是项目起点参数，可按新任务调整。
4. 最终固定的学生参考转写为“想到我家的年夜饭。奶奶把饺子端上来，一家人终于坐齐了。”教师参考转写为“嘘，咱们进屋了。你看，这一家人手里捧着什么？”
5. 后续使用 Base 模型的 `ref_audio` 与 `ref_text` 生成，常用 temperature 0.66、top_p 0.88。以完整语义句生成，再检查文字和声音身份。
6. 项目曾结合 ASR、说话人嵌入、保守裁去首尾静音和轻量增益整理。数值阈值按项目校准，不能当作任何角色的普遍合格线。

参考音频未包含在公开仓库中。持有项目参考包时可以直接配置 `clone`；只有上述文字和模型时，可以重建同类声音，仍需试听选定参考。

## 音色与表演预设

| 用途 | 项目说话人起点 | 可复用表演描述 |
|---|---|---|
| 学生对白 | Vivian | 好奇、有灵气，认真思考后再说，发现答案时自然亮起来 |
| 教师讲述 | Serena | 亲切年轻教师，像面对面讲故事，柔和清澈，含笑，有呼吸与轻重 |
| 诗人讲述 | Uncle_Fu | 温厚朴实，有画面感，声音开阔，句末有落点 |
| 朗诵示范 | Serena | 清楚连贯地示范，按诗意组织重音与换气 |

学生、教师参考录音用于后期的声音稳定；诗人和朗诵示范是项目探索过的表演预设。预设收录不表示每个候选都已获用户认可。

## 场景情绪

- 发现新事物，让语气从观察到惊喜，有一句话内部的变化。
- 真正发问，先把注意力放在对象上，句尾适度上扬。
- 猜中答案，先有短暂顿悟，再露出喜悦。
- 回忆团圆，语速舒展，温暖里带一点想念。
- 轻声进屋，整体音量收一点，保持咬字清楚。
- 祝愿与道别，真诚、明亮，末尾自然收住。

古诗示范可以分别表现爆竹的清脆、春风的柔暖、日出的开阔和迎新的喜悦。二二三节奏是这首七言诗的例子，新文稿按照自身句法处理。
