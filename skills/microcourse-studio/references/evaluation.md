# 上手与评估

在包含此技能的环境中说“用 $microcourse-studio 做三年级数学《认识二分之一》，主题是公平分一张纸，平面剪纸风，大标题黑体、正文宋体、字幕楷体。先给我审内容”。本轮应交目标、脚本、逐字稿与学习验证题。分镜设计在审批后开始；例如演示等面积对折与非等分反例，学生先选、再叠合验证。科学示例“水蒸发后去哪了”要区分可见水滴与不可见水蒸气，证据不足不能画成直接可见的水蒸气微粒。续作示例“只改S03的指针和旁白断句”，查绑定版本，改受影响 cue 和动画，重新检查相邻镜，不重做无关候选。

依赖按需发现。基础门禁只需 Python 标准库；看图、听音、可用字体、浏览器与渲染器用于实际制作。输出校验可运行 python scripts/check_media.py 成片.mp4 --manifest 项目/manifest.json，需要 ffmpeg 在 PATH 或设置 FFMPEG 为可执行文件路径，缺少时用可用的等价探测器和完整解码记录。视频无法解码、校验字段缺失或文件丢失时应阻止成片交付。离线可完成的部分继续；付费、缺字体、缺音源、无法读参考视频或无法进入剪映时明确指出受阻环节，不能暗称看过原片或已原生验收。不得上传声纹、密钥或私有素材到技能仓库。引用外部平台前核对当前资料与授权。

**自动化**　在技能目录运行 python -m unittest discover -s tests -v。合同样本验证成功路径、边界、错误输入、来源失效、重试和付费状态；fixture 内的批准仅用于测试。仓库另执行 python scripts/manage_skills.py catalog 和 check。正常运行的只读门禁输出 JSON，失败返回2。人工视觉/听感和真实服务行为单独记录。

**真实制作评测**　分别试讲一节语文、一节含单位换算的数学、一节实验科学，记录同一套模块实际复用情况。对同一选题做含错误字/单位、缺图、缺字体、长静默、离线资源失效、未知扣费、改过定稿、剪映手动改过水印的用例。首次创作执行失败最多做两次无副作用修复；无进展保留可用版与阻塞原因。每轮用相同时间点在修前/修后检查，最后从头实播。原生应用无访问权时交样稿请实机检查，记“未测”。

|指标|分子 / 分母|验收规则|
|---|---|---|
|测试通过率|通过用例 / 已执行用例|合同回归全绿，未执行另列|
|执行成功率/失败率|成功/最终失败的作业数分别除以终态作业总数|按学科、工具和版本分组；待审与运行中不入分母，原ID重试不多算作业|
|能力复用率|复用已验收原子模块的适用工序 / 全部适用工序|跨项目统计，列出需定制的工序及原因|
|费用与返工|各批实际积分、已用成片秒数、重做原因；首轮通过镜头 / 已审镜头|未授权支出为零；报价与实扣分别列明|
|成品质量|教学事实、关键动作、字音、字幕、资源完整、播放和可编辑性实测|严重问题未解决不可定稿；列遗留及用户接受记录，区分自动与人工证据|

没有实际样本的成功率和复用率填“尚无数据”，不能以离线测试通过替代课程效果或获奖证明。
