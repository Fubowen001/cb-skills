# 动画占比与积分

先按学习目标排镜。可用信息分步、图卡分类、图解、卷轴遮罩、指示线或反馈动画准确表达的，走本地。手与道具接触、遮挡、布料/液体、复杂人体运动或需带对白的角色镜头，才进入即梦候选。演示数据/科学图形用可验证的本地绘制。给用户看三组时长：正片总长、实际可见外部动画区间并集、待生成素材总秒数（含首尾余量/重叠）。占比=区间并集/正片；无统一合格比例。成本按服务报价的素材时长与条数，不按可见时长。

内容或分镜尚未批准时不生成计费素材。分镜图由本地或用户认可的图像工具制作。《元日》偏好即梦只做必要视频。用现有参考图，先最有代表性的开场/问题镜头，每镜一个最低可用分辨率候选；查当日可用模型、模式、账号、实际支持的尺寸与时长。不要把480p、2.0 Fast、2.5样片、当年活动或往次到账当成固定价格。样片转正、直接生成、超分与补帧单列，分别展示480/720/1080或实际可用档位的增量与累计；不可用填原因。优先留住已通过的动作，先评估本地增强；1080p画布本身不能再同档升清。

每批报价表写镜号、每条秒数、模型、档位、候选数、预计与最高扣费、余额（可读时）、整课剩余镜数/秒数/预算。已实扣、估算、官方上限分栏。用户批准具体批次后才确认/提交。工具只返回实扣时，明确“无预报价、不能限额”，用户主动接受单笔实扣才能提交，历史金额绝非上限。确认后不增加候选、不自动重做、不跨批借余额、不因“继续”升级高清。付费结果写回任务ID、实际扣费及状态，勿保存凭据。出错先按原ID查结果，绝不换新ID重复付费。只有无副作用的查询/下载重试至多两次。分批完成后将候选嵌回上下文供审；高清批次独立批准。超分后实测尺寸、帧率、动作与鬼影。
