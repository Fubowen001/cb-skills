# 组合工序及交付件

|工序|执行及输出|审阅方法|
|---|---|---|
|选题→内容包|确认年级、先备知识、课标或教材版本、一个核心难点、能观察的学习结果与验证问题。编写导入—探究—练习—迁移。交内容提纲、教学脚本及分角色逐字稿，含时间预算、自然换气、师生同步/独立作答安排。按实际试读修正时长。|逐字稿有独立可读版本；核对术语、原文、单位与教学推论，关键事实能指回教材页或可靠资料。有歧义保留待核，不补造来源。|
|内容通过→分镜包|每镜关联教学目标、台词、起止帧、景别、人物与道具、动作起止态、转场动机、声音触点、本地技术或外部模型、资产及版本。先定人物多视图、服色、空间、关键道具正视图与字体样张，再出独立分镜，动作复杂时补过程和尾态。|联系表逐镜显示真实图片，查漏图、重复图、错图；人物或反复出现的道具先审一张再批量改。输出可看大图、逐镜评论、导出与回读 JSON 的审阅页；意见按镜号与版本定位。|
|分镜通过→初版|把逐字稿录音对齐，生成 cue 与字幕，教学图形和互动用浏览器/PPT式进场、遮罩、路径、AE式分层关键帧实现。复杂动画用最新审定静帧占位，课堂读图和分析可有意保持安静。交离线HTML、素材、章节导航及初版说明。|演示画中画必须让人看见选择、操作、反馈；另有真正能玩的应用。由用户在整节课里评价节奏。说明哪些效果是程序实现；用户明确要 PPTX/AEP 时需交相应源文件或声明缺失。|
|初版→精修包|意见清单逐条记录镜号、台词、时间点、复现方法、修复、影响范围和证据。区分角色动作与教学演示，列出付费候选，不因比赛要求堆技术。每次只替换已验收素材，保留上个可播放版本。交新版网页、逐字稿、MP4与修改对照。|局部返工先看前一句到后一句，再查同类问题在其他镜头是否复现。全片试播后，请用户对具体版本确认修改完成。|
|定稿→原生工程包|调用 jianchuang-jianying-assistant（CapCut Mate），读取当前安装版说明与可用接口。优先本地服务，核对平台和剪映版本。先做5秒样稿，再导入命名不同的完整版，复制资源并修正路径。|分别验证视频可替换、字幕可改、底板、角色语音、配乐、音效可独立调节；可选水印为独立文字，前后两个位置关键帧实际可拖。复杂MG已烘焙时随附网页/动画源及替换方法。|
 
剪映首页草稿索引可能被运行中的应用覆盖。需要改索引时提示保存并退出；仅在确有需要时请求自动化或辅助功能权限。缺权限可请用户手动打开样稿核对。避免覆盖用户已改字幕或水印的原草稿。校准在剪映里的字号和底板，检查遮挡选取。迁移时在新路径解压、打开、检查丢失媒体，区分本机验证与跨平台未测。交标准16:9 MP4、SRT/VTT、可解压离线包、素材分轨、可编辑源及验证记录。扩展交付只在需要时加3:4三屏封面、15秒可自行配乐的无声导入、图文发布稿；宣传文案以真实制作过程为据，避免暗示已获奖。
