# 《元日》返工经验 → 可复用的验收动作

每条记「适用镜号 / 时间点 / 验证方式 / 结果 / 证据路径」。未知和未审不得填写通过。条目中出现的具体人物、诗句、古风美术与四馆，是复现故障用的案例；按学科换等价检查点。

|检查现场|曾经的问题与检查动作|
|---|---|
|跨镜头构图|逐场把首帧、关键中间帧、尾帧与前后句拼在一起。布景、光色、脸、衣饰、左右手、杯子数量与位置连续。每镜抓一个新的信息；不要反复使用同一构图充数，也不要把连续动作强行切碎。|
|物理与遮挡|帘布要先抓握、解带、受力、逐渐揭开；皮影须随物体和光源连续投射。手敲桌面时桌沿静止，手臂有支点；窗格前后遮挡合理，手指不穿木框。倒酒先倾壶、液流入杯、收壶再举杯；取旧符先脱钉，挂新符挂稳后松开。贴纸扶正再压角；印章压实抬起后才留印。局部遮罩不能把人物、手、桌子切成会漂移的纸片。|
|统一资产|门框须符合时代和结构，无裂缝、悬空或接不上木条；正视图先确认再批量替换。室内石台改木灯几须与房间色温一致，避免片尾突然焦黄。先检查整课所有依赖，实施后比对门、灯几和所有使用它们的帧。|
|语画同拍|“奶奶端饺子来啦”说到时必须看见对应人物/动作；“又响了一串”需有第二次清脆爆竹声。用真实接触帧落敲击、入杯、搁壶、落盘、木件和脚步声，风与市井声轻且疏。配乐乐器可丰富，讲解时让出人声，不逐字抽动。|
|师生声音|老师、学生、旁白身份与情绪贯穿；背诵和齐读自然换气，按一起读的设定不留重复朗读空档。查“木板”这类词内断裂、重读错字、多人名/多音字，检查邀请学生复述、游戏串词及末尾异常定格。识别软件只定位，以耳听原速上下句为准。|
|对话嘴形|每个露脸说话镜头单独对嘴角、唇线、侧脸角度、开合幅度与停声闭口；检查头转时是否跟随、旁听者嘴是否乱动。保留已认可样片，逐个复制方法而非统一坐标；已有生成嘴形不二次叠加。音量驱动近似口型须如实标注。|
|排字|建立标题、正文、字幕、拉丁拼音、公式/符号字库，各自渲染测试；案例大标题取参考二行草、正文参考一笔意、字幕楷体。查“曈曈”日旁、对比错误“瞳瞳”，拼音 tóng tóng 两个声调清晰，不能落入不可读草体。逐字缺字回退要有统一匹配。字幕按语义切成单行并紧跟音频，不缩得过小；明暗背景、衣饰、画中画、控制栏和不同屏幕分别看对比与遮挡。|
|教学设计|整卷是一幅画，手和轴一起运动，讲一句展开一段、停稳再讲下一句。背诵按节拍显字，核对页则按概念重新分组，勿重复同一版式；区分习俗与自然景象。四馆各自有适龄任务、选择过程、错误反馈、成功反馈与可游玩版本。指定左诗右图讲解时保持安静。其他学科复用“观察—表达—核对”时重设任务。|
|播放与清晰度|固定播放器与内容有效区，取样动画、静帧、切换前后和全屏，排查黑白边、拉伸和忽大忽小。动静边界预解码、以连续时钟切换；片尾不倒跳首帧，拖动后不错镜。整体观看排查令人眩晕的缩放、跳位、闪帧及长静止；60fps容器、重复帧、运动插帧、设备实播掉帧分别记录。检查插帧鬼影与手指变形。源分辨率、超分与输出画布分别标明。|
|导出与编辑|本案交付16:9、1080p60全幅，字幕可切换的网页与独立字幕源。文件完整解码、音画到尾，换电脑离线实测或标待测。抽查真实剪映时间线、首秒与后段、字幕大小/底板，不只检查JSON；分轨混音与成片一致。编辑“玻丞”水印后能拖动并添关键帧；选择恢复不等于定位了故障原因。|

**仍有瑕疵的旧镜头也要纳入测试。** 进屋时提前倒酒可剪到壶端稳，但标注机位漂移；青瓷杯应不透明，不能让液面透过杯壁。绳圈套钩、手松开、盘子落稳、蒸汽来源分别验收；低清抽帧看不清不能标通过。贴春联若尾帧双手仍贴纸，登记“未完成松手”；幕布绳结不能凭空出现。生成音轨与原配音只选批准的轨。学龄儿童饮屠苏只作历史民俗讲解，图中由成人举杯。实际通过、只剪掉问题、用户知情接受、仍待返工分开记录。

互动应用一屏一任务，拖拽提供点选替代，按钮可点区域可按低龄设备采用约44px；有返回、重试、声音开关、减少动态和键盘焦点。错误后保留学习进度，重复完成不重复集章。案例四馆采用年俗分类、诗句拼接、联系生活、表达新年心愿；其他学科按目标替换。涉及竞赛时以正式赛制核对素材使用、署名、AI披露、时长与可提交格式。
