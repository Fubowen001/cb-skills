# 原子工种接口

每项都可由组合流程或单独修订调用。统一接收 job_id、版本、shot_id/cue_id、批准的输入文件；返回状态、产物相对路径、来源、所用工具、待复核点。状态用 ready / needs_review / blocked；只有文件存在且对应检查通过才记 ready。

|工种|专属输入 → 产物|判断与兜底|
|---|---|---|
|学科审校|知识目标、教材/可靠来源、原文 → 知识证据表、易错项、答案与理由|数学按步复算，图形不随意拉伸，单位/坐标轴可读；科学实验锁定变量和观测顺序，模拟与实测分开标；语言查字形、语音和语境；历史地理核对年代、地图与比例；艺术体育按节拍、动作方向和安全距离；信息技术在目标环境复现。学段不明先标假设，关键知识无法核实时停在待审。|
|视觉母版与分镜|主题、人物、道具、时代/环境、色样、字体 → 设定板、每镜首帧及必要的尾帧|静态图片优先自行生成或用已准素材；参考影片提取的是叙事节奏与构图。锁定资产ID，修改一个共用道具时列出全部引用。|
|动作与转场|镜头起止帧、接触点、台词 → 关键姿势、可运行本地动作或生成提示词|提示词写全角色参考、景别、固定物、光向、说话者、台词时段、手从何处到何处、松手后物体状态、起落速度、结束姿态与相邻镜接点；匹配服务实际时长、比例、分辨率和参考图规格。运动不可控则固定视点、拆动作或回静帧。|
|配音与口型|role_id、voice_ref、语义完整的台词、表演意图 → 独立干声、同步字幕与嘴形|发现 expressive-voice 时复用，用户可自定义声音。先听一句并锁定同一角色参考；逐字稿与发音修正分开。分段补录后重对字幕、嘴形和相关动作。没有参考音频不能保证复刻。|
|教学动效与互动|学习目标、关键变化、错误选项及原因 → MG时间轴、课件式演示、可玩应用及画中画|PPT式分步显隐适合推导，AE式遮罩/路径适合机制或时间变化。先写学生做什么、错了如何提示、如何再试、成功如何验证。用键盘/鼠标实操，演示时指针、选项和反馈可见。|
|声音设计|动作接触帧、讲解区间、音乐授权 → 环境/拟音/音乐独立轨、音量包络与来源表|真实录音优先，讲解时整句压低配乐，场景间用乐句和音色变化。指定歌曲只有截图时核对曲名、版本与可用音源；无法取得可交默片，由用户配乐。|
|渲染与证据|时间轴、画幅、源素材规格 → 离线网页、MP4、帧与听审记录|FFmpeg/ffprobe 或等效工具完整解码；浏览器实播首尾、跳转、暂停、倍速、全屏、字幕和断网。记录环境、时长、解码帧、实际掉帧与黑边检测。无法听、看或实测则明确待验。|
|编辑交接|通过确认的定稿、媒体和分轨 → 剪映草稿及源包|先验证 CapCut Mate 实例健康、支持的原生功能、资源可读和许可。缺依赖先备齐可迁移的素材及时间表，将原生导入标阻塞，不能用平铺MP4冒充完成。|
