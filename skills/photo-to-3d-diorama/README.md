# 照片转3D微观模型

可复用 Codex skill，默认制作包含人物、地面、道具与环境的完整微观场景，不只抠出人物单件。每张照片默认一个独立模型；只有明确指定多图合并才按组处理。支持原图、卡通、皮克斯式立体动画、水墨与自定义风格。复杂或不清楚的画面先按原图约束补充参考，保守补全不可见处。

## 使用

把本目录安装到 ~/.codex/skills/photo-to-3d-diorama，下一轮对话即可用：

> $photo-to-3d-diorama 把这三张照片分别做成水墨风3D微观模型，严格保留原图元素。

指定多视角融合时说明分组，例如“第1和第2张是同一物体的正反面，合成一个；第3张独立”。

## 环境与交付

运行 scripts/preflight.py 检查本机运行环境；尚未配置时，按 references/runtime-and-formats.md 安装已有 Python/CUDA、官方代码及模型权重。技能代码本身不包含数GB运行环境，也不自动下载、登录或购买额度。参考图生成需要当前 Codex 环境中可用的图像生成能力。

默认输出真正的3D高斯 PLY/SPLAT、离线交互预览、生成记录和待人工视觉核验记录。可选导出 Blender 完整参数及代理预览。需要三角网格 GLB、骨骼或碰撞时另走对应制作流程。单图不可确定的背面必须明确标注推测，不能承诺真实背面精确还原。

第三方预览渲染库 Three.js 与 OrbitControls 的 MIT 许可保留于 assets/LICENSE.txt。重建后端由使用者单独准备，遵守其许可证。本目录不含用户照片、模型、账号信息或本机路径配置。

## 验证

用配置好的 Python 运行 scripts/test_contracts.py 可复查输入分组、源图哈希、风格参考门槛、白色像素保留和高斯格式。受限环境可用 PHOTO3D_TEST_TMP 指定可写临时目录。数字测试不替代每个实际模型的多角度视觉核验。

## 保真与分部制作

复杂角色支持按同一照片分部制作、锁定用户选定基准和风格参考、分别审看再装配；不会自行合并不同照片。高斯资产、局部审看、独立网格和设计草稿分别标注。严格交付前使用 scripts/check_delivery_review.py 核对证据记录；它不自动判断视觉质量。用户要求“通过后再看”时不提前展示候选；仅当明确请求过程审看时使用 review_requested。

用 scripts/test_delivery_review.py 验证哈希锁定、未验收阻断、表示方式检查、明确审看例外和多资产记录隔离。本机或上传限制按每次任务要求执行，不写死本案例风格、私照或服务授权。
