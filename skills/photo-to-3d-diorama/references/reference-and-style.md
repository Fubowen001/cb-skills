# 参考与风格

先逐图记录主体、数量、姿态、材质、关键颜色、背景元素、前中后景和遮挡。inventory 使用 observed 数组、inferred 数组和 layout 文字。多张独立照片不得合成拼盘；只有用户明确指定分组才融合。

默认保留有意义的背景。装饰标题和画外白边可在参考阶段排除，但实物招牌、器物花纹和文字不能擅删。主体本来就是画框或卡片时应保留。白色前景不是透明背景，保留真正 alpha，禁止全局亮度抠图。

| 风格 | 可改变 | 必须保留 |
|---|---|---|
| source | 保守补全立体结构 | 原画风和辨识色 |
| cartoon | 材质简化、柔和明暗 | 数量、姿态、布局和身份特征 |
| pixar | 电影动画式光照、圆润立体材质 | 主体身份，不自动换角色或大头比例 |
| ink | 宣纸感、干湿墨、晕染、有限设色 | 花色和白色主体，不能全部洗成灰 |
| custom | 用户指定渲染材质 | 未授权改变的原图结构 |

严格依据附图制作可从侧面、背面观看的立体微缩场景参考。保留【观察元素清单】及【数量、姿态和相对位置】，应用【风格】。前景【…】、中景【…】、远景【…】，有实体侧面、真实厚度、相互遮挡与统一地面。树叶自然弯曲，山石有侧壁，人物肢体保持原姿态。仅对【不清晰处】做【保守补全】。不添加原图没有的角色、建筑或装饰，不生成印着风景的矩形板、折纸墙或相框。保留白色主体不透明材质，背景可真正透明。

提示用于参考生成，不塞给不支持文字的后端。批量可共用调色原则，不能让不同图变成同一套场景。多图约束参考后单图重建必须如实标注，不能称为摄影测量。生成参考后先核对清单再启动推理。
